# V7 Department Management: Requirements Document

## 1. Functional Requirements
- **FR-07-1:** Unique department code normalized to uppercase.
- **FR-07-2:** Department CRUD operations restricted to `SUPER_ADMIN` and `ADMIN`.
- **FR-07-3:** Active and inactive status toggling with validation warnings.
- **FR-07-4:** Department statistics computation.
- **FR-07-5:** Audit log integration for all creation, update, and status change events.
